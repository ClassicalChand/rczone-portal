RCZONE STARTER PORTAL — README

WHAT IS INCLUDED
- index.html: responsive landing page and service directory
- login.html: demo sign-in screen
- dashboard.html: demo dashboard, request list and retailer-management preview
- style.css: blue/white responsive styling
- app.js: demo-only interactions using browser sessionStorage/localStorage

IMPORTANT LIMITATIONS
This is a front-end prototype, NOT a production-ready portal.
- No real authentication, database, API, payments, wallet, Aadhaar/PAN processing, AEPS, or government service connection exists.
- Demo logins accept any entered username/password and must never be used for real accounts.
- Demo requests and retailers are stored only in the current browser and are not securely shared across users.
- Do not collect Aadhaar numbers, PAN details, passwords, OTPs, bank details or other sensitive personal data in this demo.
- Do not claim government affiliation. Use official/authorised providers and meet applicable laws, security and data-protection requirements before going live.
- Never put secret API keys in HTML/JavaScript. Real integrations must be performed server-side.

LOCAL PREVIEW
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Use Login / Register and enter any demo values to open the demo dashboard.

FREE HOSTING START
A static preview can be hosted on a static hosting service such as Cloudflare Pages or GitHub Pages. A secure production portal with retailer accounts needs a backend, database, authentication, access controls, backups and monitoring. Check each provider's current free-tier limits before deploying.
